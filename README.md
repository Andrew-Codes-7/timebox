# Timebox

A task manager built around timeboxing: give each task a slot in the day instead of keeping an endless list.

## Features

- Drag tasks onto a day schedule, or leave them under "Anytime today"
- Categories, timers and a history of completed work
- Unfinished tasks roll over to the next day
- Undo, dark mode, and import/export of your data

## Tech

A single HTML file with vanilla JavaScript and CSS. No dependencies, no build step, no account: data is saved in the browser with `localStorage`.

## Running it

Open `index.html` in a browser.
